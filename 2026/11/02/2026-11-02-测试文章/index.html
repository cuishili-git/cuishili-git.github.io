测试：从任意目录发布

把扫描件 / 照片类 PDF 逐页交给视觉大模型，识别版式并翻译，输出 .docx。
因为这类 PDF 提取不出文字，只能按页渲染成图片让多模态模型「看图说话」；
逐页调用还带来三个好处：可并发、失败只重试单页、上下文不会超长。

启动

  • 双击 启动.bat（无黑窗）
  • 出问题双击 启动_调试.bat，报错会显示在窗口里
  • 首次换电脑：双击 install.bat 建环境装依赖（需要 Python 3.10~3.13）

使用

  1. 左侧填接口地址 / API Key / 模型（任何 OpenAI 兼容的视觉接口都能用）
  2. 拖入 PDF → 自动开始 → 右侧看进度与日志
  3. 完成后点「打开输出文件」，docx 在 PDF 同级的 输出/ 目录

没配 Key 时可以勾上「模拟模式」，它会返回一份假的翻译结果，
用来验证渲染、并发、docx 组装、公式这些链路是否正常。

各家模型填法

服务 接口地址 模型名示例
智谱 GLM https://open.bigmodel.cn/api/paas/v4 glm-4v-plus
阿里 Qwen-VL https://dashscope.aliyuncs.com/compatible-mode/v1 qwen-vl-max
豆包 https://ark.cn-beijing.volces.com/api/v3 控制台里的推理接入点 ID
OpenAI https://api.openai.com/v1 gpt-4o
中转站 服务商给的 /v1 地址 按服务商说明

当前限制

  • 表格跨页只做标记，暂不自动合并成一张表
  • 插图只输出文字描述（[图] ...），不还原原图
  • 页眉页脚靠模型识别丢弃，极端版式可能残留
  • 生成的 docx 未做字体/页边距精调，样式为 Word 默认
